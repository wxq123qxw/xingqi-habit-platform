## 🚀 安装步骤（NSIS 版）

1. 双击 **`星启-0.0.0-x64.exe`**
2. 选择安装路径（默认 `C:\Program Files\星启\`）
3. 选择是否创建桌面快捷方式（默认是）
4. 点击「安装」
5. 启动：桌面 / 开始菜单 → 「星启」

---

## 🎬 第一次启动

启动后看到「星启」紫色启动页（深紫星空背景）。

- **首次使用**：点「进入星空」→「注册新账号」（昵称 1-20 字符；密码 ≥6 位须含字母+数字+特殊符号）→ 登录
- **本地缓存**：注册/登录数据存在电脑 localStorage，**离线可用**
- **联网功能**：若一台机器上同时运行后端服务（见下），会自动同步排行榜 + 好友数据

### 📌 重点：后台运行（系统托盘）

点窗口右上角的 **`×`** **不会退出程序**，只会把窗口隐藏到 **Windows 系统托盘**（任务栏右下角的时钟附近，能看到一个紫色星星图标 ✨）。

- **想再次打开主窗口**：双击 / 单击 托盘图标，或右键菜单选「显示星启」
- **真正退出程序**：右键托盘图标 → 「退出星启」（或在 title bar 上点带方框的退出按钮，会弹确认框）
- **这是设计上的选择**：让提醒通知、后台同步、习惯打卡等不被误关

## 🖱️ 窗口贴边自动隐藏

把窗口拖到屏幕**最左边或最右边**（顶部不再触发），**保持 0.8 秒不动**，窗口会自动滑出只剩 6px 露出（QQ / Windows 11 风格）。

- 触发前 0.35 秒窗口会**轻微变浅**（opacity 1→0.78），让你看到"在变"
- 0.8 秒后窗口**滑出 + 变浅到 0.55**
- 首次成功隐藏会**弹系统通知**告诉你怎么恢复（仅一次）
- 鼠标靠近那个 6px 半透明小条 → 窗口自动滑回原位置
- 窗口最大化时不会触发隐藏

## 🔗 后端服务（可选 · 进阶）

**默认情况下软件可以独立运行**——所有数据存本地 SQLite + localStorage。

如果你和朋友想**互相看排行榜 / 互加好友**，你们需要：

1. 找一台常开的电脑（或 NAS），装 Node.js 18+
2. 在项目根目录跑：
   ```bash
   cd backend
   npm install
   BACKUP_PASSWORD="你的密码" npm start
   ```
3. 其他用户电脑的客户端会自动连 `http://<主机IP>:3001`

**详细步骤见 `/backend/` 内的 README 或项目根目录的 `npm run electron:dev` 流程。**

---

## 🛡️ 数据安全（单机模式）

- 用户密码用 PBKDF2-HMAC-SHA256 + 16 字节 per-user salt 哈希，**不可能被反向解密**
- 所有数据在用户电脑上，加密备份（`.hbf`）用 AES-256-GCM
- 即便别人拿走你的电脑文件，也读不出原始数据

## 🆘 常见问题

**Q：启动后是白屏 / 加载很慢？**
- 第一次启动有约 5-10 秒初始化时间（asar 解压 + 字体加载）。白屏是正常现象，请等一下。

**Q：排行里为什么只有我一个人？**
- 单机模式下没有跨用户数据，属正常。如需多人排行榜，见上面"后端服务"。

**Q：如何重置所有数据 / 卸载？**
- 设置 → 修改/恢复/删除 → 删除 / 恢复习惯，或直接卸载应用

**Q：登录失败 / 数据丢了？**
- 用户数据存在 Electron userData 目录：`%APPDATA%\星启\`
- 卸载前可手动备份

**Q：报"后端连接失败"提示？**
- 正常——本地版不依赖后端，登录仍能完成。提示只是通知"高级功能不可用"。

**Q：点 X 关掉窗口后打不开程序了？**
- 软件没退出，只是窗口隐藏到系统托盘（任务栏右下角时钟旁）。找到紫色星星图标右键 → 显示星启
- 真正退出只能从托盘菜单"退出星启"
